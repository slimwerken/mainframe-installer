# Mainframe-installer

Installatie van Mainframe met Jarvis. Begin op https://slimwerken.ai/installeer/ of
plak in Claude: `Installeer mijn Mainframe volgens link.slimwerken.ai/installeer`.

Deze map is de reservekopie van de installer (zelfde bestanden als op slimwerken.ai).
Hier staat niets geheims: Mainframe en de app komen pas na een geldige licentiecode.
Bron: projecten/mainframe-installer in Het Mainframe. Niet met de hand aanpassen.
